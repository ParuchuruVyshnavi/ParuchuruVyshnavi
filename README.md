## 04 / THE INVISIBLE WORK

The final interface is only one part of development.

Behind it are the decisions nobody sees: choosing a layout, reconsidering an interaction, debugging an unexpected problem, looking up documentation, or discovering that the original idea needs to change.

I'm learning to appreciate that part of the process, too.

- **Observe before implementing.** Understand what needs to be solved.
- **Experiment before assuming.** Try alternatives instead of settling for the first idea.
- **Design for people.** An interface should make sense to the person using it.
- **Respect the details.** Small decisions can change the entire experience.
- **Keep learning in public.** Projects are opportunities to turn knowledge into something tangible.

I don't expect every experiment to be perfect. I expect each one to teach me something worth carrying into the next.

## 05 / WHAT I'M BECOMING

My current direction is frontend development, with an interest in the relationship between engineering and visual design.

I'm working towards stronger skills in modern frontend technologies, more thoughtful UI/UX, and projects that demonstrate both technical understanding and creative decision-making.
